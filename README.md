# AI Token Monitor

claude.ai と Codex（chatgpt.com）のトークン使用量をリアルタイムで推定し、画面右下にオーバーレイ表示するChrome拡張機能です。

---

## 対応サービス

| サービス | URL |
|---|---|
| Claude（通常チャット） | `claude.ai/chat/*` |
| Codex | `chatgpt.com/codex/*` |

> **注意：** `claude.ai/code`（Claude Code専用UI）はiframe別オリジンのため非対応です。

---

## 機能

- 入力・出力トークン数をリアルタイム推定
- ゲージバーで使用率を視覚表示
- 80%超で黄色警告、95%超で赤色アラート
- サービスを自動判定してセレクタを切り替え
- ポップアップからトークン上限値を設定可能

---

## インストール方法

### 1. ZIPをダウンロード

[Releases ページ](../../releases/latest) を開き、`ai-token-monitor-vX.X.X.zip` をダウンロードしてください。

> ⚠️ `Source code (zip)` ではなく **`ai-token-monitor-vX.X.X.zip`** をダウンロードしてください。

### 2. ZIPを解凍

ダウンロードしたZIPファイルを解凍します。

### 3. Chromeに読み込む

1. Chromeで `chrome://extensions` を開く
2. 右上の「**デベロッパーモード**」をONにする
3. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
4. 解凍したフォルダを選択する

### 4. 動作確認

- `claude.ai/chat` または `chatgpt.com/codex` を開く
- メッセージを送受信すると画面右下にオーバーレイが表示される

---

## トークン上限値の設定

1. Chrome右上の拡張機能アイコンをクリック
2. ポップアップの入力欄に上限値を入力（デフォルト：100,000）
3. 「保存」をクリック

> 上限値はトークン数の目安です。実際の制限はプランによって異なります。

---

## トークン推定ロジック

正確なAPIトークンではなく、以下のルールで推定しています。

| 文字種 | 換算 |
|---|---|
| 日本語・中国語・韓国語 | 1文字 = 1トークン |
| 英語・記号など | 4文字 = 1トークン |

---

## 警告しきい値

| 使用率 | 表示 | 色 |
|---|---|---|
| 80%以上 | ⚠️ トークン使用量が多くなっています | 黄 |
| 95%以上 | 🚨 制限まであとわずか！ | 赤 |

---

## 既知の制限

- トークン数は**推定値**です（実際のAPIトークン数とは異なります）
- `claude.ai/code` には非対応（iframeが別オリジン）
- サービス側のDOM変更によってセレクタが無効になる場合があります

---
